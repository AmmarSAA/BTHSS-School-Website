# 🏫 BTHSS School Website  
**Bangalore Town Higher Secondary School**

---

## 📌 Project Overview

This project is a front-end website developed for **Bangalore Town Higher Secondary School (BTHSS)**.  
The website is designed to provide essential information about the school, including academic details, announcements, and contact information.

The main goal of this project was to create a clean, responsive, and user-friendly interface using fundamental web development technologies.

This is a **front-end only project** with static structure and basic form integration for UI demonstration purposes.

---

## 🎯 Project Purpose

- Provide an online presence for the school  
- Display school information in an organized format  
- Practice core front-end development skills  
- Demonstrate responsive web design using Bootstrap  

---

## ✨ Features

- Responsive homepage layout  
- Navigation bar for easy page access  
- School information sections  
- Contact / Inquiry form (UI level)  
- Mobile-friendly design  

---

## 🛠️ Technologies Used

- **HTML5**  
  Used for website structure and content layout.

- **CSS3**  
  Used for styling, layout customization, and visual design.

- **Bootstrap**  
  Used for responsive grid system, components, and faster UI development.

---

## 📂 Project Type

- Front-End Only  
- Static Website  
- No Backend Integration  
- Forms are UI-based (no database connection)

---

## 🚀 How to Run the Project

1. Download or clone the project files  
2. Open the project folder  
3. Open `index.html` in any browser  

No installation or server setup required.
